# Repository Guidelines

## Project Structure & Module Organization
`ragbot` is organized by runtime surface:
- `services/api/app/`: FastAPI gateway, agent graph/nodes, auth, retrieval, storage, observability.
- `services/worker/`: ingestion pipeline (`connectors/`, `jobs/`, lifecycle/reconciliation logic).
- `cli/`: `rag` command-line entrypoint.
- `contracts/`: shared agent/tool domain contracts. HTTP OpenAPI is generated by FastAPI; see `contracts/README.md`.
- `packages/node-client/`: TypeScript client; it must typecheck in CI.
- `eval/`: evaluation runners and datasets.
- `infra/`: Docker, Helm chart, SQL migrations, and Qdrant init scripts.
- `tests/`: regression and integration tests.

## Build, Test, and Development Commands
- `python -m venv .venv`: create a local environment.
- `pip install -e ".[dev,postgres,qdrant,worker,observability]"`: install the project with all development/runtime extras.
- `cp .env.example .env`: create local configuration; never commit `.env`.
- `uvicorn services.api.app.api:app --reload --host 0.0.0.0 --port 8000`: run API locally.
- `python -m pytest -q`: run the complete Python suite.
- `python -m pip check`: validate installed dependency consistency.
- `python -m services.api.app.storage.migrations`: apply pending PostgreSQL migrations.
- `python scripts/export_openapi.py --output build/openapi.json`: export canonical OpenAPI.
- `docker compose config -q`: validate Compose before deployment.
- `helm lint infra/helm/ragbot`: validate the Helm chart.
- `cd packages/node-client && npm install --no-package-lock --ignore-scripts && npm run typecheck`: validate the Node client.

## RAG Correctness Invariants
Treat these as compatibility constraints, not implementation details:
- ingestion and retrieval MUST use the same embedder and vector dimension;
- an existing Qdrant collection dimension MUST match `QDRANT_DIM`;
- changing embedding model/dimension requires reindexing into a compatible collection;
- identical content in different documents/tenants is separate logical evidence and MUST NOT be repository-wide deduplicated;
- re-ingestion writes the new view before pruning stale chunks/vectors;
- deleting a Source must purge its indexed documents/chunks/vectors before tombstoning it;
- tenant and ACL filters must be applied before evidence reaches synthesis;
- multi-replica deployments require shared PostgreSQL and Qdrant, never process-local stores.

## API and Contracts
FastAPI/Pydantic models are the source of truth for HTTP OpenAPI (`/openapi.json`). Do not maintain a second handwritten HTTP schema. When agent/tool payloads change, synchronize `contracts/types.py`, `contracts/types.ts`, `packages/node-client/src/types.ts`, and `contracts/tools.schema.json` as applicable.

## Database Migrations
Never rely on PostgreSQL `/docker-entrypoint-initdb.d` for upgrades. Add ordered SQL files under `infra/migrations/`; the migration runner records applied filenames in `schema_migrations` and is used by CI, Compose, and Helm. Existing migrations must remain immutable after release; schema corrections belong in a new migration.

## Testing Guidelines
Tests run via `pytest` and primarily use `unittest.TestCase` patterns. For agent/retrieval/ingestion changes, add regression coverage. CI gates Python 3.10/3.12, PostgreSQL migrations/native FTS, Node client typechecking, Docker Compose validation, and Helm lint/rendering.

## Commit & Pull Request Guidelines
Use focused Conventional Commit-style messages (`feat:`, `fix:`, `docs:`, `test:`, `chore:`). PRs should state rationale, externally visible behavior, migration/reindex implications, test evidence, and remaining limitations.

## Security & Configuration Tips
Do not commit secrets, local documents, generated bytecode, or credentials. Configure runtime through environment variables and `docs/CONFIGURATION.md`. Empty `RAGBOT_API_KEYS` disables API-key enforcement and is suitable only for trusted local development. Current API keys are service-level credentials; `tenant_id` and `user_id` are caller assertions, not an identity-provider integration.
