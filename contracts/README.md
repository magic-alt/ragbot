# Contracts

Ragbot has one canonical HTTP API schema: the OpenAPI document generated by the
FastAPI application from its Pydantic request/response models.

- Running service: `GET /openapi.json` and `GET /docs`.
- Offline export: `python scripts/export_openapi.py --output build/openapi.json`.
- `types.py` / `types.ts`: shared agent/tool domain contracts.
- `tools.schema.json`: tool-call JSON schemas used outside the HTTP layer.

A hand-maintained `openapi.yaml` was intentionally removed because it had drifted
from the runtime API (wrong version, removed endpoints, missing current routes).
Do not add a second manually maintained HTTP schema. If a checked-in OpenAPI
artifact is required for publishing later, generate it in CI from `app.openapi()`
and verify it as a build artifact.

When domain contracts change, update the Python and TypeScript forms in the same
pull request and typecheck the Node client.
